# Our Model: from a skin to a moving skeleton

Interactive viewer: open the GitHub Pages link of this repository.

Each body is an Anny skin (newborn to 85 years, both sexes); its own rig and its own MS-Human-700 skeleton (132 bones) are computed from the skin, kept inside the skin in every frame, and driven by recorded 100STYLE motion. Use the layer switches for skin, rig, skeleton and muscles.
